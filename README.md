Short paragraph about graceful degradation and service workers:


Graceful degradation is the idea that even if parts of an application stop working or conditions become worse, the important features should still continue functioning instead of the entire app failing. Service workers relate to this because they help websites continue working even without internet by caching important files and resources. In this lab, the recipe website was still able to load after turning the network offline because the service worker saved the files locally. This made the app more reliable and is an example of graceful degradation since the app still remained usable under limited conditions.
